# AI prompt registry

| Prompt | Version | Purpose | Untrusted input | Mutation authority |
|---|---|---|---|---|
| Lead intelligence | phase7-v1 | Internal summary and draft suggestions | Delimited, redacted question/notes | none |
| Deterministic fallback | phase7-v1 | Provider-independent operator guidance | minimized facts only | none |

System constraints prohibit protected-trait inference, lending/legal decisions, valuations/offers, invented property facts, invented consent, public web investigation, assignment, scoring, scheduling, and sending. The model must separate facts from suggestions and recommend human review.
