# Ask Magic Mike Design System

Canonical design sources: `PUBLIC_DESIGN_SYSTEM.md`, `DESIGN_SYSTEM_OMEGA.md`, `app/globals.css`, and `tailwind.config.ts`.

Phase 6 preserves the black/deep-navy base, warm gold and ivory hierarchy, restrained ruby alerts, and limited cyan operational accents. Typography uses readable system fallbacks with display serif only for hierarchy. UI content remains live HTML; lead details are never flattened into generated images.

Phase 6 adds reusable states for: test banner, permission hold, human approval, carrier-disabled SMS, sequence inventory, copilot facts/suggestions, and delivery evidence. The PII-free AI-assisted internal backdrop is registered in `PHASE6_VISUAL_ASSET_REGISTER.md` and remains unconnected to Production notifications pending brand approval.

Accessibility requirements: visible focus, keyboard semantics, high contrast, reduced-motion support, 44px-class touch targets where interactive, responsive stacking, descriptive iframe title, plain-text email fallback, decorative-image empty alt, and no critical information inside images.
