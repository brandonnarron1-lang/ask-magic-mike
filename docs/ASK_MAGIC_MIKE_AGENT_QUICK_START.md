# Ask Magic Mike Agent Quick Start

1. Sign in only through the approved Lead Center address. Never share access.
2. Your queue contains only leads assigned to you unless an administrator grants
   a broader role.
3. Open the lead, confirm consent and permitted contact channel, and protect all
   contact/property details.
4. Accept the assignment, record attempted/contacted outcome, add a concise
   brokerage note, and set the next action.
5. Record appointment requests, scheduled/confirmed outcomes, nurture, signed
   client, closing, bad lead, or unavailable status accurately.
6. Do not download, forward, screenshot, or paste lead PII into personal tools.
7. Log out on a shared device. For a lost device, notify the administrator
   immediately so sessions and Push enrollment can be revoked.
8. If another agent's lead is visible or editable, stop and report a security
   incident; do not open or export it.
